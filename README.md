# Naruto Video Labeler

一个纯前端、离线运行的对战录像事件标注器，用于视频分析与训练复盘。

## 使用方式

1. 打开 GitHub Pages 页面。
2. 在浏览器本地选择一段录像。
3. 再选择分析器生成的候选事件 JSON。
4. 点击候选事件跳转到对应时刻，逐条接受或拒绝。
5. 导出标注 JSON。

录像与报告仅在本地浏览器处理，不会上传到本仓库或网页服务器。

## 范围

这是离线复盘与数据标注工具；不连接、不操作游戏客户端，也不用于在线对战自动化。
